# 最少参考素材

先复用已有身份、场景和声线；每段只挂本段可见身份、空间和必要关键物件的最小集合。不为每个机位、每个表情单建参考，不挂未出场全组人物。现有锚点不能稳定关键视角或物件外观时才增图，并说明新增解决什么缺口。

## 人物

一人一张合图：同一身份、服装与比例，正面/侧面/背面全身加放大面部；脚部完整、脸可辨。背景必须纯白无缝，均匀柔光，只留轻微接触影；不使用灰底、环境或其他人物。无文字、标签、边框和水印。视频中该Subject是一名人物，不能把合图多视图生成人物分身或分屏。

## 场景

一张单幅无人全景或俯视全景，只呈现完整场地、门窗、家具、通路、固定地标与基础光。所有座位空置；镜面、玻璃和屏幕不出现人物、脸、身体、剪影或摄影者倒影。不写角色在屋内的站位、活动或身份，家具用方位命名而非角色姓名。全景保持自然透视与尺度，不以鱼眼或拼贴代替布局。

场景与道具都只生成一个连续画面，不出现旁置照片、人物肖像、参考图缩略图、视图小窗、拼板、分屏或边框。人物三视图合图要求不进入这两类。确属剧情必要的照片道具只保留其本体外形，参考图默认以空白/不可辨内容呈现，不自动摆出内部照片或扩散成照片墙。

## 道具

默认一件目标物，完整轮廓、清晰三分之四视角，独立放在纯白无缝承托面上，仅有轻微接触影；不悬托在手中，不出现手掌、手指、手臂、身体、持有者或额外展示支架。折叠、柔软或需支撑的物品采用自然平放或稳定姿态，不让模型补出抓持者。成套物只有剧情不可分割的组成件可一起出现，不能为介绍用途增添散落配件。

只写尺寸、形状、颜色、材质、纹理与需要固定的开合状态；尺寸用实际比例或数值，不以手掌、佩戴或持握动作作尺度参照。取放、使用者、交接和剧情状态留给视频分镜。手机/纸张不显示可读文字、人物照片或截图；容器不为展示内容自动开箱铺开，必要内部状态另按剧情明确。

## 风格与参数

场景主图先定风格；人物图可参考该风格，但不复制其环境。生图风格只保留媒介、渲染、材质、色彩与光影，将净化后的共享描述记为 `lock:image-style`。人物五官属于人物外观；角色表演、全体人物一致、照片/屏幕呈现等视频要求不进入场景和道具生图。视频 `lock:style` 保持原样。若原Subject锁夹带人物、持握、使用情境或照片陈列，为该资产另记 `lock:image:别名`，只保留静态外观；不得为通过逐字检查把污染内容塞回生图。无净化需求的旧锁可沿用，校验优先采用image锁。

复用参考文件时也按用途分离：人物合图不作为空景或道具的整图内容参考；只传必要的风格/材质依据，工具不能区分风格与内容时用净化后的文字。每条实际生图正向prompt都明确本资产类型、单幅/单件构图和对应排除项，不能只写在中文说明或无效负向字段里。提交前核对实际genPrompt与所附图片，出图后检查空景、无手、无旁置图，失败项不标记为可用素材。

尺寸、步数、随机等沿用用户最近设置；未设置时分辨率1080×720。人物合图画幅需保证各视图可读，不用无关“长边1536–2048”覆盖用户参数。文件名等于别名，PNG；路径未生成可留空。声音设计按声音指南登记，导出只验证已知真实时长。

每项用实际登记别名作为三级标题，写一个完整prompt代码块，直接描述当前资产，不附空白结构或故事案例。
