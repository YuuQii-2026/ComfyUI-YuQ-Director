# 镜头与观看关系

本工作流不使用装饰性推近、拉远、光学变焦或反复推拉，不用这些动作代替叙事。确有必要的尺寸变化可由人物接近、远离或有信息价值的切镜完成；用户明确要求某种摄影方式时再采用。不要把全部镜头改成静止中景，先设计人物行动与空间关系。

## 选择依据

| 观看任务 | 镜头处理 | 必须写明 |
|---|---|---|
| 呈现人物之间的压力和选择 | 同框调度、前中后景与遮挡关系 | 观众先看谁、谁控制空间、什么动作改变关系 |
| 跟随有效行动 | 沿可行通道跟拍或横向移动 | 行动目标、相机位置、路径、出现的新信息、终点构图 |
| 揭示原本不可见的事实 | 由人物动作带出遮挡后的对象，或有动机的转向/横移 | 遮挡来源、触发、揭示顺序及观众最终看到什么 |
| 在同框层次间转移注意力 | 表演引导、景深关系或必要移焦 | 起始焦点、转移原因、目标；移焦不等于相机移动 |
| 强调不可替代的信息 | 有理由的切镜与动作/视线匹配 | 新镜头增加的事实及其与前镜的空间关系 |
| 让完整表演成立 | 固定构图内的行动与反应 | 可见动作、关系变化、起止状态；不靠空等撑长度 |

自然英文写动作句，不堆器材、焦距、电影感标签。写“触发 → 相机/人物如何变化 → 新信息 → 收束构图”，不凭空增加复杂器械或运动。中等幅度、正常速度无需反复声明。

## 路径与剪辑

先固定地标与人物世界坐标，再定相机方位、朝向和屏幕投影；相机变动不改变世界位置。横移产生视差，转向改变观看方向，跟拍应保持人物路径可行；焦点变化不改机位。需要弧线或顺序复合运动时，每个阶段都须有独立信息作用，速度、轴线、遮挡与通道兼容。

切镜发生在信息、行动阶段或观看关系改变处，不跟着标点或生成段边界切。守住必要动作和发声过程；需要声画分离时明确声源、持续时窗及听者状态，不能让另一人接嘴。

同一连续镜头跨段时主动启用接力，接缝保留机位、焦点、运动方向/速度与动作阶段；不重新推近、重新起步或额外空等。真正换机位、换场或跳时才独立生成。接口细节见 [consistency-locks.md](consistency-locks.md)。
