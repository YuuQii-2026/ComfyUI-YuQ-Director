# 身份、空间、状态与接缝

## 锁定数据

`一致性圣经.md` 只保存重复使用的事实：`lock:style`、`lock:subject:N`、`lock:voice:Sx`、`lock:ambience:N`，有生成配乐才放 `lock:music`。`lock:negative` 保留给导出，不承担当前 Turbo + BasicGuider 的约束。锁内不放本段动作、未来剧情或例子。

`lock:style` 以 `The target video is ` 开头，完整句逐字置于每段 detailed_description 开头。生图优先使用 `lock:image-style` 的纯媒介/质感描述及 `lock:image:别名` 的该资产静态外观；缺省兼容原风格与Subject锁。图像锁不包含人物表演、持握、全局照片指令，不改变视频锁。Subject锁写稳定身份、服装或场景结构，台词旁声线锁逐字复用。阶段性换装、损坏或持物变化登记状态，不悄悄重写永久设定。

## 首帧与状态

每段提示词都是新文本请求。独立生成时必须明确实际首帧；接力时也须写明接缝画面，不能用“延续上一段”代替事实。首帧只包含构图中看得到的身份特征、姿态、手部/持物、视线、世界位置、物件状态、机位、地标与基础光，不重复不可见鞋袜等信息。

每个会改变的对象在 `## 状态时间线` 逐段登记，单元格为起始状态或“起始状态 → 完成结果”；不可见写明实际位置。连续故事时间中本段起始应等于同一时间线上前段结束；变化须有画内过程或真实的跳时依据。`时间跳跃：是` 只用于剧情确实跳时，不能用来消除生成不连续警告。

每个动作明确触发、执行者、身体/物件、可行路径和结果；到达、取出、交接等只做一次。完成后从结果状态推进，不能回到起点重复操作。问答期间不插入无关拿放手机、转头往返或整理衣服。

## 空间

场景以固定方位和地标建简短平面关系：门窗、家具、通路、主要光源；人物用相对固定地标的位置与距离。再确定轴线侧、相机朝向和本机位可见投影。换机位可以改变画面左右，不能搬动世界坐标。

每个 Shot 保留本构图合理可见的空间锚点和同源基础光；特写可只保留局部材质、边缘或背景色，不要求所有地标同时入镜。效果光、屏幕光只改变局部，不能无依据切成黑屋。人物纯白参考底与合图布局不带入成片；成片环境和光线来自场景 Subject。

## 接力决策与时间

先设计镜头；相邻生成段属于同一未剪切镜头、同一时间线且动作和机位连续时，主动把后段标为接续。并非只有超过15秒才可使用，也不能仅因同场景就启用。首段不接力；明确换机位、换场、跳时则独立生成。

三处必须一致：分镜 `长镜头跨段：是（接续上一个分镜）`、提示词标题 `（接续上一个分镜）`、导出 `latentRelay: true`。标 `连续镜头：是` 的后段必须接力。上下游启用状态、实际 AV latent 路径与工作流接入也要核对；写了文字不等于已送入上下文。

接缝记录前段末尾与当前首帧的机位、景别、焦点、运动方向/速度、站位、姿态、持物、光线和动作阶段。持续动作按原方向发展，已完成事件不再执行；不强加每段开头1.5–2秒静止、段尾收稳或对白提前结束的固定配额。

当前插件 `duration.py` 与 `nodes.py` 按 `latentRelay` 决定上下文补偿：`final_output` 段长指裁切后目标，接力视频上下文22帧、24fps，即22/24秒；音频上下文24帧。H3 生成帧数贴近17n+5网格，实际成片秒数可能略有偏差。只有确认所用工作流在采样头部保留并裁掉这22帧时，接力段新事件的采样时间戳才用“成片时间 + 22/24”；不可再额外叠加等待，也不全局给独立段加0.92秒。未知版本先核对实际节点和裁切，不猜偏移。

修订上游接力源时检查后续依赖链；独立段文本改动只影响本段。文件一致、JSON开关正确与成片连贯分别记录。
