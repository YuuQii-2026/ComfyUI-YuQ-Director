# 分镜叙事

## 从事件得到镜头

先写一条场景因果链：人物当前要什么 → 谁或什么阻拦 → 观众看见哪项证据 → 人物如何选择 → 结果如何迫使下一步发生。已有剧本保留关键事实、台词和先后关系；缺少因果时先修中文分镜，不让英文摄影词掩盖问题。

把事件拆成必要的观看节点，每个节点回答“这一刻观众需要知道什么”。镜头必须承担至少一项：建立必要空间、呈现行动、揭示证据、改变观众判断、呈现有后果的反应。重复已知信息的角度、情绪标签和无后果的表情删去。悬念来自人物与观众的信息差、受阻的选择和可见代价，不靠拖延回答。

## 信息的先后

- 先安排观众与人物谁先发现，再选择看人物、对象还是两者关系。关键事实必须有可见或可听依据；不要让反应先于触发，也不要在 summary 宣称正文未呈现的结论。
- 对白服务争取、拒绝、试探、隐瞒或决定；画面呈现台词没有重复说明的关系与后果。保留必要台词，不把情节缩成轮流站着念句子。
- 一个问答可在同一镜头内完成，用注意力、人物距离和遮挡变化呈现关系；换发言者不自动切镜。只有新角度能提供必要信息或改变判断才切。
- 反应必须有对象与后果，允许与发言并行；短反应无需独立生成段。事件只发生一次，其后明确结果状态及下一步，禁止回到动作起点。
- 区分故事时间和播放时间。回忆、插叙、平行线要明确归属与时间关系；只提往事时仍拍当下，不擅自生成闪回。不能因请求独立生成而虚构时间跳跃。

## 镜头与节奏

先设计整场镜头，再按生成上限划段。一个连续镜头可以跨段接力；一个生成段也可以容纳数个有理由的剪切。镜头长短服从事件、表演与信息，不设景别比例、固定两镜或逐句正反打。段尾可以落在新事实或尚未完成的选择，下一段接其后果，避免每段重开场。

逐镜表只写能拍到的事实：时窗、观看重点、机位与可见空间、动作的起因和结果、发声者与台词、净占时、衔接。删掉镜头后若因果与信息都不变，优先合并。时长不足时删冗余或重排相邻内容，不凭空加台词、手机操作、看回去或慢动作。
